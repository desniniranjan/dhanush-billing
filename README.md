# Sai Srinivas Agencies — Billing Portal

A billing and inventory management portal for industrial hardware agencies.

---

## Features

- **Billing** — Add items, enter customer details, and generate invoices instantly
- **Invoice History** — View and manage all past invoices
- **Inventory Management** — Add, edit, and delete products with pricing
- **WhatsApp Integration** — Send formatted bills to customers in one click
- **Bill Preview** — Review the invoice before sending or saving
- **No backend needed** — All data saved locally in the browser
